# Protein Hub - PRD: User Flow

## 8. User Flow --- Guest to Distributor

The full journey from discovery to active distributor status:

1. **Discovery**: Prospect finds Protein Hub via social media, referral link, or search.
2. **Landing**: Lands on public homepage → watches 3-minute teaser video.
3. **Engagement**: Reads FAQ or interacts with chatbot for initial questions.
4. **Registration**: Clicks 'Register for Business Presentation' → fills form → selects schedule.
5. **Preparation**: Receives confirmation with pre-presentation instructions.
6. **Presentation**: Attends business presentation (online or in-person).
7. **Conversion**: Decides to proceed → pays PHP 2,500 onboarding/training fee.
8. **Onboarding**: Receives login credentials → gains access to Member Portal.
9. **Training**: Completes Module 1 (sequential unlocking) → unlocks Module 2.
10. **Operation**: Runs their own business using the Protein Hub system and recipes.
11. **Retention**: Pays annual subscription renewal to maintain portal access.
