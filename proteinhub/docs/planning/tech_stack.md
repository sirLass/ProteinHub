# Development Planning: Tech Stack

## Core Technologies (Proposal/Prototype Phase)
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (per Next.js default)
- **Data Handling**: Mock JSON files & Browser LocalStorage (No live database involved for current phase)
- **Authentication**: Simulated Mock Auth (Hardcoded credentials for demonstration)
- **Video Hosting**: Embedded private sources (Vimeo/YouTube Private)
- **Chatbot**: Simulated interactive chat components

## Deployment
- **Platform**: Vercel

## Key Libraries
- **Forms**: React Hook Form + Zod
- **UI Components**: Shadcn/UI (Radix UI)
- **Analytics**: Vercel Analytics / PostHog
